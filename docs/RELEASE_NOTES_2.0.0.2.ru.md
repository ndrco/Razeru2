# Razeru 2.0.0.2

Технический выпуск делает прямое управление подсветкой Razer Viper устойчивым
после запуска приложения и кратковременных ошибок доступа к USB/HID.

## Изменения

- Запуск мыши больше не зависит от успешного необязательного запроса версии
  прошивки.
- Отключённая или временно недоступная Viper автоматически открывается заново.
- После ошибки feature report устаревший дескриптор закрывается, затем
  выполняется новое подключение.
- Повторные подключения ограничены одной попыткой в две секунды.
- Работа клавиатуры по-прежнему не зависит от наличия мыши.

## Проверка выпуска

- Release-сборка x64 завершена успешно.
- Все файлы анимаций клавиатуры и мыши прошли проверку.
- Переключение цветов RU↔EN подтверждено на подключённых Huntsman V2 TKL и
  Razer Viper через производственный путь выполнения.
- Установленное приложение и комплектные библиотеки совпадают с проверенной
  Release-сборкой.
