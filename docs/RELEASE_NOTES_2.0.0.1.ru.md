# Razeru 2.0.0.1

Исправление добавляет прямую индикацию языка на логотипе мыши Razer Viper
(`1532:0078`) без Synapse, Chroma SDK, служб и драйверов Razer.

## Основные изменения

- Добавлен аппаратный профиль Viper: HID-интерфейс `MI_00`, usage
  `0001:0002`, 91-байтовые feature reports, прошивка проверенного устройства
  `1.7`.
- Добавлен защищённый загрузчик анимаций Chroma Mouse 9×7. Для единственного
  светодиода Viper используется штатная ячейка логотипа `(7,3)`.
- Цвет логотипа синхронизирован с кадром активной раскладки: зелёная анимация
  для RU и розовая для EN в стандартном профиле.
- Команда extended static отправляется с `NOSTORE=0`, поэтому кадры не
  записываются во встроенную память мыши.
- Viper является необязательным устройством: отсутствие мыши не мешает запуску
  и прямому управлению Huntsman V2 TKL.

## Проверка выпуска

- Release-сборка x64 завершена успешно.
- Проверены 163 клавиатурные и 22 mouse-анимации; повреждённый ввод отклонён.
- На подключённой Razer Viper подтверждены запрос прошивки, статический цвет и
  переключение логотипа RU↔EN одновременно с клавиатурой.
- Во время десятисекундного прогона приложение оставалось отзывчивым и не
  накопило измеримого процессорного времени.
