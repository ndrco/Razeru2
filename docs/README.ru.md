# Руководство пользователя Razeru

## Назначение

Razeru регулярно определяет раскладку клавиатуры активного приложения Windows и
сопоставляет её языковой идентификатор с настроенной сценой Chroma. Сцена может
содержать анимации клавиатуры, мыши, коврика, гарнитуры, кейпада и устройств
Chroma Link. Для клавиатуры поверх анимации можно наложить постоянную цветовую
карту и реактивный либо волновой эффект нажатия.

Razeru не записывает вводимый текст. Глобальный низкоуровневый перехватчик
получает только события нажатия и отпускания виртуальных клавиш, необходимые для
подсветки. Приложение работает локально; в ходе аудита сетевой код и телеметрия
не обнаружены.

## Первый запуск

1. Подключите совместимую клавиатуру Razer Chroma.
2. Установите и запустите приложение Razer Chroma, откройте **Chroma Apps** и
   включите этот модуль. Razer Synapse не требуется.
3. Запустите инсталлятор Razeru, затем Razeru из меню «Пуск».
4. Если конфигурация не загрузилась, разрешите создать настройки по умолчанию.
5. Найдите значок Razeru в области уведомлений Windows.
6. Щёлкните значок правой кнопкой и выберите **Settings / Настройки**.

Одновременно работает только один экземпляр. При повторном запуске появится
сообщение об ошибке. Во время блокировки сеанса Windows приложение приостанавливает
перехватчик и вывод Chroma, после разблокировки восстанавливает их.

## Настройки

Диалог настроек содержит три функциональные области:

1. **Языковые сцены** — добавление и удаление языка ввода Windows, выбор файла
   `.chroma` для каждого типа устройства и скорости анимации.
2. **Подсветка клавиатуры** — включение постоянного слоя, окраска отдельных
   клавиш, очистка карты, выбор режимов смешивания и сцены.
3. **Эффект клавиш** — выбор «нет эффекта», Reactive или Wave, цвета,
   длительности кадра и числа кадров.

Сохранение записывает `Razeru.json` рядом с `Razeru.exe` и сразу просит основной
процесс перечитать файл. Команда Chroma Editor открывает редактор Razer для
файлов `.chroma`.

## Минимальное ПО Razer

Из выбираемых пользователем продуктов Razer установите только **Razer Chroma
App**. Его App Engine, службы Chroma SDK и драйверы устройств — обязательные
общие компоненты, которые должны остаться. Razer Synapse, Axon, Cortex и THX
Spatial Audio для Razeru не нужны. Отклоняйте рекламные приложения, которые
предлагает установщик Razer.

Таблица компонентов, официальные источники, порядок чистой установки и проверки
приведены в документе [«Минимальные компоненты Razer»](RAZER_REQUIREMENTS.ru.md).

## Файлы и обновление

Стандартный каталог установки:

```text
%LOCALAPPDATA%\Programs\Razeru
```

Основные файлы:

- `Razeru.exe` — процесс области уведомлений и монитор раскладки;
- `RzruUI.dll` — интерфейс настроек MFC и работа с JSON;
- `CChromaEditorLibrary64.dll` — подписанный мост анимаций Razer; системный SDK
  отдельно устанавливает Chroma App;
- `Razeru.json` — пользовательская конфигурация;
- `Animations\` — ресурсы `.chroma`;
- `docs\` — локальная документация.

При обновлении заменяются бинарные файлы и документация, но существующая
конфигурация и анимации не перезаписываются. При удалении они также сохраняются.
Если настройки больше не нужны, оставшийся каталог Razeru можно удалить вручную.

## Автозапуск

Инсталлятор предлагает необязательную задачу **Start Razeru when I sign in**.
Она добавляет заключённый в кавычки путь к программе в:

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
```

Интерфейс настроек управляет той же записью текущего пользователя. Системная
служба и драйвер не устанавливаются.

## Формат конфигурации

`Razeru.json` — JSON в UTF-8. Относительные пути к анимациям разрешаются от
рабочего каталога приложения, поэтому `Animations` должен находиться рядом с
исполняемым файлом. Предпочтительнее менять параметры через интерфейс.

| Поле | Назначение |
| --- | --- |
| `primary_lang`, `sub_lang` | Язык интерфейса как идентификаторы языка Windows |
| `devicesAnimation` | Включает анимацию устройств Chroma, кроме клавиатуры |
| `keyboardEffect[]` | По одной сцене на языковой идентификатор раскладки |
| `keyboardLayout` | Числовой Windows `LANGID`, например 1049 для русского |
| `*Animation` | Относительные пути `.chroma` для типов устройств |
| `speed` | Число кадров за шаг; значения меньше 1 нормализуются |
| `keyEffect` | Тип эффекта нажатия, RGB-число, длительность и число кадров |
| `backlightEffect` | Постоянный слой, режимы смешивания и матрица цветов клавиш |

Некорректные или отсутствующие метаданные анимации нормализуются до безопасных
положительных значений времени и числа кадров. Однако синтаксически неверный
JSON всё ещё не загрузится. Перед ручной правкой сохраните резервную копию.

## Решение проблем

- **Chroma DLL not found:** установите или восстановите отдельное
  [приложение Razer Chroma](https://www.razer.com/chroma), включите
  **Chroma Apps** и перезапустите Razeru. Переустанавливать Razeru не требуется.
- **Failed to load the Razeru Chroma bridge:** восстановите Razeru и пакет
  Microsoft Visual C++ Redistributable x64.
- **No Chroma devices / no keyboard:** подключите совместимую Chroma-клавиатуру,
  проверьте её в Chroma App и перезапустите Razeru. Переустановка Razeru не
  исправляет физически отключённое устройство.
- **Invalid DLL signature:** не заменяйте библиотеку Razer непроверенной копией;
  переустановите Razeru из доверенного пакета.
- **Нет анимации раскладки:** добавьте точный язык ввода Windows в настройках и
  проверьте существование всех указанных файлов.
- **Мышь анимируется, а клавиатура чёрная при включённых слоях:** используйте
  Razeru 1.2.0.4 или новее. В этой версии ручной композитор переведён с
  совместимого вызова `SetEffectCustom2D`, который текущая Chroma App может
  принять без видимого вывода, на низкоуровневый эффект SDK. Для сравнения
  временно отключите постоянную подсветку и эффект клавиш: тогда клавиатура
  проигрывается автоматическим путём.
- **Нет значка:** проверьте скрытые значки области уведомлений и отсутствие уже
  запущенного экземпляра Razeru.
- **Конфигурация отклонена:** восстановите `config\Razeru.json` из исходников
  либо загрузите настройки по умолчанию и сохраните их.

Для диагностики отладочной сборки просматривайте `OutputDebugString` в Visual
Studio или Sysinternals DebugView.
