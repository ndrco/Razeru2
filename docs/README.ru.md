# Руководство пользователя Razeru 2

Razeru 2 следит за языком ввода активного приложения Windows и напрямую
выводит настроенную клавиатурную анимацию `.chroma` на Razer Huntsman V2
Tenkeyless. Поверх анимации можно смешивать постоянную подсветку языка и
реактивные эффекты нажатия.

Razeru не записывает вводимый текст. Низкоуровневый клавиатурный перехватчик
видит события клавиш только для отображения настроенного реактивного эффекта.

## Первый запуск

1. Подключите Huntsman V2 TKL (`1532:026B`) непосредственно к USB.
2. Установите и запустите Razeru 2. Приложения Razer для этого не нужны.
3. Если появится запрос, разрешите создать стандартный `Razeru.json`.
4. Найдите **Razeru 2 Lang indicator** в области уведомлений Windows.
5. Смените язык ввода в активном окне и проверьте изменение подсветки.

В меню значка доступны **Settings**, **Editor** и **Exit**. **Editor** открывает
официальный веб-редактор Razer в браузере и не загружает локальный Chroma SDK.

## Файлы и обновления

Стандартный каталог установки для текущего пользователя:

```text
%LOCALAPPDATA%\Programs\Razeru
```

В нём находятся `Razeru.exe`, `RzruUI.dll`, `Razeru.json`, `Animations`,
лицензия и документация. Библиотек среды Razer в Razeru 2 нет. Обновление и
удаление сохраняют конфигурацию и каталог анимаций.

`Razeru.json` — JSON в UTF-8. Относительные пути считаются от каталога
приложения. Поддерживаются обычные анимации клавиатуры 6×22 и уже входящие в
проект файлы Keyboard Extended 8×24.

## Текущие ограничения оборудования

Razeru 2.0 содержит один проверенный профиль: Razer Huntsman V2 Tenkeyless USB
`VID_1532&PID_026B`, HID-интерфейс `MI_03`, аппаратная матрица 6×17. Логические
столбцы Chroma 1-17 соответствуют аппаратным 0-16. Команды не отправляются
мыши, коврику, гарнитуре, кейпаду, Chroma Link, беспроводным вариантам и другим
ID клавиатур, даже если старые поля этих устройств пока видны в настройках.

## Диагностика

- **Клавиатура не найдена:** переподключите её напрямую, проверьте USB ID в
  «Диспетчере устройств» и наличие `HidUsb` на интерфейсе `MI_03`.
- **Найдена, но не отвечает:** завершите другие программы подсветки и повторите
  запуск — они могут конкурировать за канал feature reports.
- **Цвета чередуются или меняются хаотично:** не запускайте одновременно Razer
  App Engine, эффекты Chroma, «Динамическое освещение» Windows или другой RGB-
  контроллер. Подсветкой должна управлять одна программа.
- **Анимации не загружаются:** восстановите исходный каталог `Animations` и
  проверьте пути в `Razeru.json`.
- **Не открываются настройки:** держите `RzruUI.dll` рядом с `Razeru.exe` и
  установите актуальную среду Microsoft Visual C++ x64.
- **Второй экземпляр завершается:** глобальный mutex намеренно разрешает только
  один работающий экземпляр Razeru.

Перед удалением программ и фильтров Razer выполните поэтапную проверку из
документа [«ПО Razer: требования и удаление»](RAZER_REQUIREMENTS.ru.md).
