# ПО Razer: требования и удаление

## Требования во время работы

Razeru 2 не требует Razer Synapse, Chroma App, App Engine, служб Chroma SDK,
`RzChromatic64.dll`, `RzChromaSDK64.dll`, фильтрующих драйверов Razer и
`CChromaEditorLibrary64.dll`. Программа напрямую использует Windows SetupAPI и
HID API.

Первый аппаратный профиль намеренно ограничен:

| Параметр | Поддерживаемое значение |
| --- | --- |
| Клавиатура | Razer Huntsman V2 Tenkeyless |
| USB ID | `VID_1532&PID_026B` |
| HID-интерфейс | `MI_03`, usage page `0x000C`, usage `0x0001` |
| Матрица подсветки | 6×17; логические столбцы 1-17 переходят в 0-16 устройства |
| Необходимые драйверы Windows | `usbccgp`, `HidUsb`, `kbdhid` |
| Проверенная при разработке прошивка | `1.0` |

Обычный ввод и подсветка работают через штатные HID-драйверы Microsoft.
Razeru 2 отправляет временные feature reports: прошивку не меняет и профили в
постоянную память устройства не записывает. Другие модели Razer отклоняются,
чтобы не посылать им непроверенный формат команд.

Команда **Editor** открывает официальный веб-редактор Razer:
<https://chroma.razer.com/ChromaEditor>. Интернет и браузер нужны только для
редактора; фоновая работа Razeru 2 от сети не зависит.

## Безопасная проверка перед удалением ПО Razer

Не начинайте с удаления драйверов. Сначала сохраните возможность отката и
проверьте новый транспорт:

1. Скопируйте в безопасное место `Razeru.json` и `Animations`.
2. Завершите старый Razeru и запустите Razeru 2 из отдельного тестового каталога.
3. Выполните `RazeruHidTest info`: должны отобразиться HID-путь и прошивка.
4. Временно включите красный, зелёный и синий эффекты, затем восстановите
   `spectrum`.
5. Убедитесь, что Razeru 2 меняет анимацию вместе с языком ввода активного окна,
   а клавиатура печатает нормально.
6. Отключите автозапуск программ Razer, остановите их процессы и службы,
   перезагрузитесь и повторите пункты 3-5. Для защищённых служб могут
   потребоваться права администратора.
7. Только после успешной проверки без служб удалите продукты Razer их штатными
   деинсталляторами и снова перезагрузитесь.

Сейчас в системе может присутствовать составной путь `RZCONTROL`/`RzCommon` и
виртуальное устройство `RzDev_026b`. Это дополнения Razer, а не зависимости
Razeru 2. После штатного удаления и перезагрузки физическая клавиатура должна
остаться на цепочке `usbccgp` -> `HidUsb` -> `kbdhid`.

Совместный запуск Razer App Engine или его LampArray-моста `razerwdl.exe` с
Razeru на проверенной машине вызывал конкурирующие, внешне хаотичные цвета.
Отключения «Динамического освещения» Windows недостаточно, чтобы остановить сам
мост Razer.

## Проверка после удаления

В «Диспетчере устройств» проверьте:

- клавиатура видна как `USB\VID_1532&PID_026B`;
- HID-интерфейс использует драйвер Microsoft `HidUsb`;
- клавиатурный ввод использует `kbdhid`;
- нет кодов ошибок и повторных отключений;
- `RazeruHidTest info` и Razeru 2 продолжают работать.

Не удаляйте пакеты драйверов или значения фильтров в реестре вручную до
завершения штатного удаления и перезагрузки. Если фильтр Razer останется,
сначала определите его точный опубликованный INF командой
`pnputil /enum-drivers` и убедитесь, что он не используется активным
устройством. Удаление работающего фильтра ввода может временно отключить
клавиатуру и требует прав администратора.

Если после очистки прямой HID-доступ пропал, переподключите клавиатуру к другому
USB-порту и сначала проверьте штатные HID-драйверы Microsoft. Переустановка ПО
Razer остаётся способом отката на время сбора точных ошибок и HID-путей.
