# Razeru 2.0.0.4

Восстановление подсветки клавиатуры и мыши при сбросе временной яркости
устройства в ноль, в том числе после разблокировки Windows.

## Изменения

- Временная яркость устанавливается в 100% перед первым выводом и после
  повторного подключения.
- При возобновлении подсветки после разблокировки яркость инициализируется заново.
- Во время вывода эффектов яркость проверяется примерно каждые две секунды:
  ноль заменяется на 100%, ненулевая яркость сохраняется между инициализациями.
- Изменение яркости подтверждается обратным чтением. Встроенный профиль и
  flash-память устройства не записываются.
- Добавлены команды диагностики и аппаратной регрессии для обоих устройств.
- Обновлены версия инсталлятора и документация на русском и английском языках.

## Проверка

- Release x64 и статический анализ завершены без ошибок; остались три прежних
  предупреждения в стороннем заголовке JSON.
- Проверены 163 клавиатурные и 22 мышиные анимации; повреждённый ввод отклонён.
- На Huntsman V2 TKL и Viper пройдены тесты первого вывода, периодического
  восстановления через существующее подключение, сохранения яркости 128 и
  повторной инициализации при возобновлении.
- Установка сохранила конфигурацию и автозапуск. Пройдены три синтетических
  цикла сессии; затем пользователь подтвердил работу подсветки в ответ на
  просьбу проверить настоящую блокировку и разблокировку Windows.
- Сон, перезагрузка и отключение питания для этой версии повторно не проверялись.
