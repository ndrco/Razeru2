# Razeru 2.0.0.0

В Razeru 2 локальная зависимость от Razer Chroma SDK заменена прямым USB
HID-управлением Razer Huntsman V2 Tenkeyless (`1532:026B`). Приложение работает
через штатный HID-стек Windows и не требует Synapse, Chroma App, App Engine,
служб Razer, фильтрующих драйверов производителя или
`CChromaEditorLibrary*.dll`.

## Основные изменения

- Проверено прямое управление интерфейсом `MI_03`, usage page `0x000C`, usage
  `0x0001`.
- Исправлена матрица устройства 6x17: логические столбцы Chroma 1-17 переходят
  в физические 0-16, включая Tab, Caps Lock и анимацию нажатых клавиш.
- Добавлен собственный загрузчик обычных и расширенных файлов `.chroma`.
- Команда Editor открывает официальный веб-редактор:
  <https://chroma.razer.com/ChromaEditor>.
- Пользовательский x64-инсталлятор сохраняет существующие `Razeru.json` и
  `Animations`, одновременно удаляя старые DLL анимаций Chroma из каталога
  приложения.

## Проверка выпуска

- Release-сборка x64 завершена успешно.
- Независимый тест прочитал все 163 входящие в проект анимации клавиатуры.
- Аппаратный запрос открыл точный интерфейс `MI_03` и получил версию прошивки
  `1.0`.
- В таблице импорта исполняемого файла только зависимости Windows и Visual C++;
  DLL Razer не загружаются.
- После удаления HID-пакетов Razer проверенная клавиатура продолжила работать
  через Microsoft `input.inf` / `HidUsb`.

## Файл выпуска

- Имя: `Razeru-Setup-2.0.0.0-x64.exe`
- SHA-256: `B1E26C719ABCD7AC3DB3B236F0EFF217496E15B12CA1E8A4CD85E4C3C512F63B`
- Authenticode: подписи нет; Windows может показать предупреждение SmartScreen.

Первый аппаратный профиль намеренно поддерживает только Huntsman V2 Tenkeyless
с USB ID `1532:026B`. Другие модели Razer отклоняются до отдельной проверки
формата их HID-отчётов.
